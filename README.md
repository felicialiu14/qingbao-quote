# 轻报 · 光储产品报价工具

一个可在电脑和手机浏览器中使用的中文报价工具。输入成本、汇率和利润点，按产品品类自动计算最终报价。

## 使用

打开本项目的 GitHub Pages 网站即可使用。也可以下载仓库 ZIP、解压后，双击 `index.html` 离线运行。无需安装依赖或启动服务器。

### 报价规则

利润点输入 `18` 表示乘以 `1.18`，输入 `8` 表示乘以 `1.08`。汇率按「1 报价币种 = 所填金额人民币」填写。

| 品类 | 公式 | 最终报价小数位 |
| --- | --- | --- |
| 组件 | 单瓦成本 ÷ 汇率 × (1 + 利润点 ÷ 100) | 3 |
| 锂电池 | 成本 ÷ 汇率 × (1 + 利润点 ÷ 100) | 0 |
| 逆变器、辅材 | 成本 ÷ 汇率 ÷ 1.13 × (1 + 利润点 ÷ 100) | 0 |
| 支架、线缆 | 成本 ÷ 汇率 ÷ 1.13 × (1 + 利润点 ÷ 100) | 2 |

所有金额按对应精度四舍五入。

- **组件**：可填写功率（W），单片金额 = 功率 × 已显示的单瓦报价，保留 3 位小数。
- **逆变器**：可填写带单位的功率，例如 `10 kW`，用于区分规格。
- **锂电池**：可填写容量，例如 `100 Ah` 或 `5.12 kWh`，用于区分规格。
- **自定义品类**：可选择两种计算公式，报价保留 2 位小数。
- 合计按组件单片金额及其他产品最终报价相加，小数位采用已报价产品中的最高精度。

## 功能

- 默认 5 行产品，可继续添加，无固定数量上限。
- 每一行可分别设置成本、利润点、品类及规格。
- 可统一设置汇率、报价币种和默认利润点。
- 草稿自动保存在当前浏览器中。
- 支持报价单预览、复制、CSV 导出、打印 / 保存 PDF。
- 对外报价单包含产品、规格和报价，不包含成本及利润点。
- 在线入口要求同意使用统计：同意且统计连接成功后才开放报价工具，拒绝或撤回后锁定页面；报价内容不上传。
- 独立管理员后台：邮箱登录、近 1 / 7 / 30 天统计、IP 筛选和当前页 CSV 导出。

## 数据保存

报价在浏览器内计算。每位使用者的草稿保存在自己的浏览器中，用户之间不会共享报价数据。更换浏览器、网址或本地文件位置后，草稿可能各自独立；清理浏览器数据可能清除草稿。

访问统计使用单独的 Supabase 数据库，只记录访客同意后的公网 IP、服务器接收时间、随机会话编号和两类使用事件。报价成本、利润、产品明细与客户内容不会上传。应用内统计记录保留 30 天，按小时清理；数据库权限只允许绑定的唯一管理员读取近 30 天的数据。

配置未完成时 `analytics-config.js` 的 `enabled` 保持 `false`，统计不运行，在线报价入口也不开放。报价区域在 HTML 中默认隐藏并设为 inert，未同意时不加载计算脚本；访客同意并收到统计接口的成功响应后才进入。拒绝、撤回、跨标签页撤回或浏览器隐私信号都会锁定入口。用户可稍后重新选择；连接失败不会偷偷进入或发送报价内容。

这属于静态网站的页面入口限制，不是服务器身份鉴权；公开源代码及下载到电脑上的本地版本不受此限制。本地文件仍可离线计算。管理员入口是 `admin/`，页面公开但所有数据查询都受数据库授权保护；隐藏链接不作为权限控制。设置方法见 [后台部署说明](DEPLOYMENT.md)。

## GitHub Pages 部署

1. 将本项目文件上传到 GitHub 仓库的 `main` 分支根目录。
2. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 选择 **main** 分支和 **/(root)**，保存并等待部署完成。

根目录包含 `.nojekyll`，可直接托管静态 HTML、CSS 和 JavaScript，无需构建。部署方式见 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 文件结构

```text
index.html          页面
style.css           样式与移动端布局
app.js              交互、草稿与报价单
calc.js             十进制金额计算与品类精度
tests/calc.test.cjs  计算回归检查
.nojekyll           静态托管标记
admin/              管理后台界面
analytics*.js/css   可选统计与公开配置
privacy.html        访客统计说明
supabase/           数据库迁移与写入函数
```

如需运行计算检查，安装支持 BigInt 的 Node.js 后执行：

```sh
node tests/calc.test.cjs
```

普通使用者不需要安装 Node.js。

权限、采集及同意开关的开发检查：安装锁定依赖后运行 `npm test`（或 `pnpm test`）。测试使用内存 PostgreSQL，不连接生产数据库。
